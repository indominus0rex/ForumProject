```markdown
# Project Overview

Embedded tremor-detection system with two tiers:

1. **MicroPython firmware on ESP32** — sensor reading, on-device FFT/feature extraction, logistic regression classification, haptic feedback
2. **Offline Python on host** — data analysis, scikit-learn training, visualization

## Hardware Contract (do not break)

- I2C: `I2C(0, scl=Pin(22), sda=Pin(21), freq=400000)`
- MPU6050 (GY-521) at `0x68`
- LED: `Pin(2, Pin.OUT)`
- Sampling: 128 samples @ 100 Hz
- FFT: in-place Cooley-Tukey, Hann window, DC mean removed

## Current Build (2026-08-27 lock)

- 4 IMUs via TCA9548A multiplexer
- CH0: dorsal wrist proximal (primary)
- CH1: thenar volar
- CH2: thumb proximal phalanx dorsal-radial 20° (pill-rolling)
- CH3: index proximal phalanx dorsal (ET postural)
- LRAs deferred (GPIO25/18/19/20 unpopulated)

## Key Technologies

- Python 3.11 host (numpy, scikit-learn, matplotlib)
- MicroPython ESP32 firmware
- Signal processing: FFT, feature extraction
- ML: logistic regression, 4-class (rest/postural/kinetic/grasp)
```

### 3c: System Architecture note

**File:** `C:\Users\Admin\Documents\Obsidian Vault\01-Project-Overview\System Architecture.md`

```markdown
# System Architecture

## Pipeline

```
GY-521 (I2C 400 kHz) → 100 Hz sampler → 128-sample window
  → feature_extract.compute()   (15 floats)
  → scaler.apply()              (z-normalise)
  → logreg.forward()            (4 logits → softmax → argmax)
  → apply_feedback()            (LED GPIO 2 + LRA PWM GPIO 25)
  → print to Thonny (pred, conf, probs)
```

## HSP Stages (firmware/stages/)

1. `safety.py` — bounds checking
2. `sensor.py` — IMU readout
3. `stationarity.py` — signal quality gate
4. `fft.py` — frequency analysis
5. `features.py` — 15-feature extraction
6. `classify.py` — logistic regression inference
7. `haptic.py` — LRA/LED feedback
8. `audit.py` — logging

## Host-Firmware Contract

- Feature order must match between `host_scripts/train_classifier.py` and `firmware/common/feature_extract.py`
- Model weights exported from host → pasted into `firmware/common/model.py`
- CSV format for pilot data: label-prefixed 3-axis samples

## Files

| File | Role |
|------|------|
| `firmware/embedded_main_hsp.py` | Main loop (flash last) |
| `firmware/common/feature_extract.py` | 15-feature extractor |
| `firmware/common/logreg.py` | 4-class inference |
| `firmware/common/scaler.py` | z-normalise |
| `firmware/common/model.py` | Baked weights |
| `host_scripts/train_classifier.py` | Offline trainer |
```
