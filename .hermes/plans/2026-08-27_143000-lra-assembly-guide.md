# LRA Integration Assembly Guide Creation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Create a detailed step-by-step assembly guide with labeled images for integrating Linear Resonant Actuators (LRAs) into the wearable IMU tremor monitoring system.

**Architecture:** The guide will combine textual instructions, annotated diagrams, and reference to existing skills and firmware documentation. It will be structured as a markdown document with embedded image references and callouts.

**Tech Stack:** Markdown, image annotation tools (to be determined), Hermes skills (wearable-sensor-mounting, wearable-sensor-wiring, wearable-sensor-integration), firmware source files.
