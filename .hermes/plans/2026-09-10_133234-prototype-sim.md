# Plan: Standalone host-simulation prototype of the Plan B loop

## Goal

Create `prototype/` (new, self-contained, pure-stdlib host code) that simulates a shaking hand, runs the Plan B suppression math sample-by-sample, and prints how much shake is left — runnable with one command and no hardware.

## Current context / assumptions

- Repo root `C:\ForumProject`; `python` = 3.11 hermes venv (has matplotlib + numpy, but the prototype must NOT need them — pure stdlib so it runs on any stock Python for demos).
- Algorithm source of truth to mirror (read-only, do NOT import from `firmware/` — the prototype is standalone so it can be zipped/emailed alone):
  - `firmware/common/bandpass.py` — 4th-order IIR (2 biquads), 3-12 Hz @100 Hz.
  - `firmware/common/pll.py` — phase detector `sample*cos(phase)` -> LPF alpha 0.1 -> PI loop -> NCO, freq clamp 3-12 Hz, lock after 50 good samples.
  - `firmware/common/predictor.py` — `phi_pred = phi + 2*pi*f*0.015`.
  - `firmware/common/anticancel.py` — `duty = |sin(phi+pi)|*amp*gain*1023`.
  - `firmware/plan_b/combo_b7_fit.py` — gates: silent unless locked + amp >= 0.03; dominant-axis projection; fusion weights (prototype simulates ONE channel only, ch0 wrist).
- Simplifications vs device (document in `prototype/README.md`, never silently diverge): single channel, no TCA/mux, no LRA electrical model (duty number only), no cooldown state machine, fixed gain 0.8, float math (MicroPython float quirks out of scope).
- The honest metric: residual RMS ratio (shake left after ideal anti-phase push vs before), plus lock time and % of time locked. No claim this equals on-body effect (LRA force model absent — say so in output footer).

## Architecture / proposed approach

Three small files, no packages, no deps: `prototype/sim.py` (tremor generator: drifting 4-9 Hz sine + slow voluntary sway + noise, seeded RNG), `prototype/loop.py` (the b7 math chain reimplemented in ~80 lines of stdlib), `prototype/run.py` (wires gen -> loop for N seconds, prints metrics + writes `out.csv` for Excel). A `prototype/check.py` script is the TDD gate: asserts the output metrics dict has the right keys and the residual ratio is < 1.0 on the default scenario.

```python
"""Synthetic hand signal: drifting tremor + voluntary sway + noise. stdlib only."""
import math
import random


class Hand:
    def __init__(self, fs=100.0, seed=7):
        self.fs = fs
        self.rng = random.Random(seed)
        self.t = 0.0

    def sample(self):
        # tremor freq drifts 5.5 -> 7.5 Hz over 20 s (phase never fixed)
        f = 6.5 + 1.0 * math.sin(2 * math.pi * 0.05 * self.t)
        # voluntary sway 0.4 Hz, large but out of tremor band
        vol = 0.5 * math.sin(2 * math.pi * 0.4 * self.t)
        tremor = 0.15 * math.sin(2 * math.pi * f * self.t)
        noise = 0.01 * (self.rng.random() - 0.5) * 2.0
        self.t += 1.0 / self.fs
        # x = tremor axis, z carries gravity
        return tremor + 0.05 * vol, 0.02 * vol, 1.0 + 0.1 * tremor + noise
```

### Task 3 — `prototype/loop.py` (b7 math, ~80 lines, stdlib)

Mirror of combo_b7 math for ONE channel. Create `prototype/loop.py` verbatim:

```python
"""Plan B loop for one channel: bandpass -> PLL -> predict -> anti-phase. stdlib only."""
import math

FS = 100.0
AMP_GATE = 0.03
FIXED_GAIN = 0.8
PREDICT_S = 0.015
MAX_DUTY = 1023


class Biquad:
    def __init__(self, b0, b1, b2, a1, a2):
        self.b0, self.b1, self.b2, self.a1, self.a2 = b0, b1, b2, a1, a2
        self.x1 = self.x2 = self.y1 = self.y2 = 0.0

    def step(self, x):
        y = self.b0 * x + self.b1 * self.x1 + self.b2 * self.x2 - self.a1 * self.y1 - self.a2 * self.y2
        self.x2, self.x1, self.y2, self.y1 = self.x1, x, self.y1, y
        return y


def bandpass_sections(fs=FS, lo=3.0, hi=12.0):
    f0 = math.sqrt(lo * hi)
    Q = f0 / (hi - lo)
    w0 = 2 * math.pi * f0 / fs
    c, s = math.cos(w0), math.sin(w0)
    out = []
    for q in (Q, Q * 1.5):
        a = s / (2 * q)
        n = 1 + a
        out.append(Biquad(a / n, 0.0, -a / n, -2 * c / n, (1 - a) / n))
    return out


class Loop:
    def __init__(self):
        self.bp = bandpass_sections()
        self.phase = 0.0
        self.freq = 6.0
        self.integ = 0.0
        self.perr = 0.0
        self.lock_n = 0
        self.locked = False
        self.mx = 0.0
        self.amp_sm = 0.0

    def step(self, x, y, z):
        self.mx += 0.02 * ((x) - self.mx)  # DC track, x is tremor axis in sim
        s = x - self.mx
        f = s
        for b in self.bp:
            f = b.step(f)
        amp = abs(f)
        self.amp_sm += 0.05 * (amp - self.amp_sm)
        pin = f / (self.amp_sm + 0.05)  # amplitude-normalized PLL drive
        perr = pin * math.cos(self.phase)
        self.perr += 0.1 * (perr - self.perr)
        wn = 2 * math.pi * 1.0 / 0.707
        kp = 2 * 0.707 * wn / FS
        ki = wn * wn / (FS * FS)
        self.integ += ki * self.perr
        self.freq = min(12.0, max(3.0, 6.0 + kp * self.perr + self.integ))
        self.phase = (self.phase + 2 * math.pi * self.freq / FS) % (2 * math.pi)
        if abs(self.perr) < 0.1:
            self.lock_n += 1
            self.locked = self.lock_n >= 50
        elif abs(self.perr) > 0.2:
            self.lock_n = 0
            self.locked = False
        if amp < AMP_GATE or not self.locked:
            return 0, amp
        pred = (self.phase + 2 * math.pi * self.freq * PREDICT_S) % (2 * math.pi)
        duty = abs(int(math.sin(pred + math.pi) * amp * FIXED_GAIN * MAX_DUTY))
        return min(MAX_DUTY, duty), amp
```

### Task 4 — `prototype/run.py` + `prototype/README.md` (green)

Create `prototype/run.py` verbatim:

```python
"""Run sim -> loop, print metrics, write CSV. Usage: python prototype/run.py [--seconds 10] [--seed 7] [--csv prototype/out.csv]."""
import argparse
import math
import sys

sys.path.insert(0, "prototype")
from sim import Hand
from loop import Loop, MAX_DUTY


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--seconds", type=float, default=10.0)
    ap.add_argument("--seed", type=int, default=7)
    ap.add_argument("--csv", default="prototype/out.csv")
    a = ap.parse_args()
    hand = Hand(seed=a.seed)
    loop = Loop()
    n = int(a.seconds * 100.0)
    res_before = 0.0
    res_after = 0.0
    duties = []
    lock_at = None
    locked_n = 0
    rows = []
    for i in range(n):
        x, y, z = hand.sample()
        duty, amp = loop.step(x, y, z)
        duties.append(duty)
        if loop.locked:
            locked_n += 1
            if lock_at is None:
                lock_at = i / 100.0
        # ideal-push residual model: push cancels sin component proportionally
        push = (duty / MAX_DUTY) * (1.0 if amp > 1e-9 else 0.0)
        left = max(0.0, amp - push * amp)
        res_before += amp * amp
        res_after += left * left
        rows.append((round(i / 100.0, 2), round(x, 4), round(amp, 4), duty, loop.locked))
    with open(a.csv, "w") as f:
        f.write("t,x,amp,duty,locked\n")
        for r in rows:
            f.write("%s,%s,%s,%s,%s\n" % r)
    import math as m
    ratio = m.sqrt(res_after / res_before) if res_before > 0 else 1.0
    print("residual_ratio=%.3f" % ratio)
    print("lock_time_s=%.2f" % (lock_at if lock_at is not None else -1))
    print("locked_frac=%.3f" % (locked_n / n))
    print("mean_duty=%.1f" % (sum(duties) / n))
    print("note=ideal-push model, not on-body effect; LRA force unmodeled")


if __name__ == "__main__":
    main()
```

## Risks, tradeoffs, and open questions

- Duplication drift: `loop.py` is a copy of device math, not an import — any tuning of `firmware/plan_b/combo_b7_fit.py` must be hand-ported. Mitigation: header comment in both files pointing at each other; keep the mirror to ONE channel and fixed gain so the surface is tiny.
- Ideal-push metric overclaims by construction: residual_ratio will look good (often < 0.5) because the model assumes the push works. The README + stdout `note=` line exist to stop anyone screenshotting it as efficacy. Never remove that line.
- Single channel only: fusion weights and dominant-axis logic are not exercised here. Follow-up (not this work): `--channels 4` mode with 3 extra noisy copies to demo fusion gain.
- Open: keep `prototype/` out of MicroPython flash tooling — add nothing to Thonny instructions; if someone flashes it by accident it is harmless (no `machine` imports) but useless. Consider a `pyproject`/lint guard later, not now (YAGNI).
