# Plan: Plan-B firmware that fits ESP32-DevKitC

## Goal

Ship one minimal MicroPython firmware (`firmware/fit_main.py` + `firmware/plan_b/combo_b7_fit.py`) that runs stable on a stock ESP32-DevKitC at 100 Hz with 4 IMUs via TCA, no ISR I2C, no CNN, and measured RAM/flash headroom.

Status 2026-09-10: `firmware/plan_b/combo_b7_fit.py` + `tests/test_b7_fit.py` implemented and green (8/8 tests, existing suppress/pll/plan_b/actuate still green). Pushes folded in: (1) 4-IMU fusion via process_multisample with static weights TODO auto-tune, (2) dominant-axis projection instead of magnitude, (4) amplitude-normalized PLL drive. Task 3-7 (fit_main, pin fix, budget gate, smoke) remain.

## Current context / assumptions

- Repo root: `C:\ForumProject` (Windows, MSYS bash, `python` = 3.11, use `uv` for deps, no `pip`).
- Current full pipeline `firmware/embedded_main_hsp.py` (269 lines) loads 12 stage objects at boot (lines 115-140), allocates `window` 128x3 plus `multi_window` 4x128x3 (lines 99-103), and does 4x TCA9548A select + I2C reads inside `Timer` ISR `sample_callback` (lines 150-237). B3 (`combo_b3_dnn_pll.py`) needs baked `common/model_dnn.py` weights.
- `firmware/common/cnn1d.py` (108 lines) does Conv1D as triple-nested pure-Python loops (~40k MACs/window). Too slow for the 1.28 s window on this board. Stays on host.
- `firmware/common/config.py:13` has `LRA_PINS = [18, 19, 20]`. GPIO20 does not exist on most DevKitC boards. `docs/assembly_checklist.md:294` already flags this.
- Stage contract: every stage in `firmware/stages/*.py` implements `process(self, frame: dict) -> dict`. Frame is a plain dict (`firmware/stages/__init__.py:18`, `STAGE_ORDER` lines 28-41).
- Tests are plain Python, no pytest required: `sys.path.insert(0, "firmware")` then functions + `if __name__ == "__main__"` block. Example: `tests/test_suppress.py` prints `All suppress stage tests passed!`.
- MicroPython files run on-device; no `numpy`/`scipy` in `firmware/` (hard rule).

## Architecture / proposed approach (4-IMU revision 2026-09-10)

Same b7_fit core, but 4 IMUs via TCA9548A in the polling loop (never ISR).
Only ch0 (dorsal wrist) runs the sample-by-sample PLL at 100 Hz.
ch1-3 are round-robin, one extra read per tick (each ~33 Hz, still Nyquist-ok
for 4-12 Hz tremor), filling small magnitude buffers for window-end coherence.
No `multi_window` 4x128x3. RAM: 1x128x3 window + 3x64 magnitude floats.

```python
"""B7 fit — DevKitC-safe: sample PLL + fixed/adaptive gain, no FFT/DNN/CNN."""
import math

NAME = "b7_fit"
DESCRIPTION = "sample-by-sample bandpass/PLL/predictor/anticancel, amplitude-gated, no classifier"
PERCEPTION = "none"
SUPPRESSION = "S1_pll_fit"
GATE_OK = True

AMP_GATE = 0.03  # ignore sub-noise residual (g units after bandpass)


class Combo:
    def __init__(self, fs=100.0, pll_bandwidth=1.0,
                 prediction_ms=15.0, initial_gain=0.5, fixed_gain=None):
        from common.bandpass import BandpassFilter
        from common.pll import PLL
        from common.predictor import PhasePredictor
        from common.anticancel import AntiPhaseGenerator
        from common.adaptive_gain import AdaptiveGain
        self.fs = fs
        self.fixed_gain = fixed_gain
        self._bp = BandpassFilter(fs=fs, low_hz=3.0, high_hz=12.0)
        self._pll = PLL(fs=fs, center_freq=6.0, bandwidth=pll_bandwidth)
        self._pred = PhasePredictor(fs=fs, prediction_ms=prediction_ms)
        self._ac = AntiPhaseGenerator(max_duty=1023)
        self._ag = AdaptiveGain(initial_gain=initial_gain)
        # expose as ._sup-like shape so old tooling keeps working
        self._sup = self

    @property
    def pll(self):
        return self._pll

    def _gain(self):
        if self.fixed_gain is not None:
            return self.fixed_gain
        return self._ag.get_gain()

    def process_sample(self, x, y, z):
        mag = math.sqrt(x * x + y * y + z * z) - 1.0
        filt = self._bp.process_sample(mag)
        phase, freq, _ = self._pll.update(filt)
        pred = self._pred.predict(phase, freq)
        amp = abs(filt)
        if amp < AMP_GATE or not self._pll.locked:
            duty = 0
        else:
            duty = self._ac.compute_duty(pred, amp, self._gain())
        if self.fixed_gain is None:
            self._ag.update(amp)
        return int(duty)

    def process(self, frame):
        window = frame.get("window") or []
        last = 0
        for r in window:
            last = self.process_sample(r[0], r[1], r[2])
        frame["suppress_duty"] = int(last)
        frame["pll_freq"] = self._pll.freq
        frame["pll_locked"] = self._pll.locked
        frame["adaptive_gain"] = self._gain()
        frame["label"] = frame.get("label", "unknown")
        frame["plan_b"] = NAME
        return frame

    def reset(self):
        self._bp.reset()
        self._pll.reset()
```

### Task 4 — Implement `firmware/fit_main.py` (polling, 4-IMU round-robin, lazy imports)

File: create `firmware/fit_main.py` (new, ~160 lines). Do NOT touch `firmware/embedded_main_hsp.py`.

Polling budget (10 ms/tick, @400 kHz): ch0 read every tick (~1 ms)
+ one round-robin secondary ch1/2/3 (~1 ms) = ~2 ms/tick, well inside budget.
ch0 magnitude stream drives `Combo.process_sample` live at 100 Hz.
Secondaries append magnitude-only (1 float, not xyz) into 3x64 ring buffers.
At window end (every 128 ticks) compute thumb-index / finger-wrist coherence
proxy (same Pearson helper as `firmware/stages/features.py:44-56`) for logging
only — never gates the LRA. LRA = ch0 PLL duty only.

Copy verbatim:

```python
"""fit_main.py — DevKitC-safe minimal loop: poll 1 IMU, b7_fit PLL, LED+LRA.

Hardware: ESP32-DevKitC, 1x GY-521 @0x68 (SDA=GPIO21, SCL=GPIO22),
LED=GPIO2, LRA=GPIO25 via MOSFET (200Hz PWM). No TCA mux, no Timer ISR.
Flash order via Thonny: common/bandpass.py, common/pll.py,
common/predictor.py, common/anticancel.py, common/adaptive_gain.py,
common/gy521.py, plan_b/combo_b7_fit.py, then fit_main.py as main.py.
"""
import time
import gc

SAMPLES = 128
SAMPLE_MS = 10  # 100 Hz polling
I2C_SDA = 21
I2C_SCL = 22
LED_PIN = 2
LRA_PIN = 25
LRA_FREQ = 200


def _host_sanity():
    # host-only smoke: proves combo wiring without hardware
    from plan_b.combo_b7_fit import Combo
    c = Combo(fs=100.0, fixed_gain=0.8)
    w = [[0.0, 0.0, 1.0]] * SAMPLES
    f = c.process({"window": w})
    assert 0 <= f["suppress_duty"] <= 1023
    return True


def main():
    gc.collect()
    try:
        from machine import I2C, Pin, PWM
    except ImportError:
        # host run: just prove wiring, then exit
        _host_sanity()
        print("fit_main host sanity ok")
        return
    from common.gy521 import GY521
    from plan_b.combo_b7_fit import Combo

    led = Pin(LED_PIN, Pin.OUT)
    lra = PWM(Pin(LRA_PIN), freq=LRA_FREQ, duty=0)
    lra.duty(0)
    i2c = I2C(0, scl=Pin(I2C_SCL), sda=Pin(I2C_SDA), freq=400000)
    try:
        sensor = GY521(i2c)
    except Exception as e:
        print("Sensor init failed:", e)
        return
    combo = Combo(fs=100.0, fixed_gain=0.8)
    window = [[0.0, 0.0, 0.0] for _ in range(SAMPLES)]
    idx = 0
    gc.collect()
    print("fit_main online: poll 100Hz, b7_fit fixed_gain=0.8")
    while True:
        t0 = time.ticks_ms()
        x, y, z = sensor.read_3axis()
        window[idx][0] = x
        window[idx][1] = y
        window[idx][2] = z
        idx += 1
        duty = combo.process_sample(x, y, z)
        # drive output per-sample; window replay only for logging path
        lra.duty(int(duty))
        led.value(1 if duty > 0 else 0)
        if idx >= SAMPLES:
            idx = 0
            gc.collect()
        # pace to 10ms without Timer ISR
        dt = time.ticks_diff(time.ticks_ms(), t0)
        if dt < SAMPLE_MS:
            time.sleep_ms(SAMPLE_MS - dt)


if __name__ == "__main__":
    main()
```

## Risks, tradeoffs, and open questions

- Fixed gain 0.8 is a guess (safe starting point, avoids adaptive overshoot on first wear). Tradeoff: weaker cancellation vs no surprise buzz. Tune after smoke: try 0.5 / 0.8 / 1.2, keep the one that suppresses without discomfort. TODO marker in code should flag this.
- Amplitude gate 0.03 g + `pll.locked` requirement means silence until lock (~50 samples / 0.5 s). Tradeoff: no false buzz vs 0.5 s onset delay. Acceptable for Plan B.
- Single IMU only (ch0 dorsal wrist). Multi-IMU coherence (thumb-index 0.6 from `firmware/stages/features.py`) is dropped for fit. Revisit only after B7 is stable; needs second board or S3.
- B3 DNN gate intentionally excluded from default (weights ~5KB + features + FFT cost RAM/CPU). Optional follow-up: `fixed_gain=None` + lazy DNN import behind a flag, only if budget gate still passes.
- B6 CNN stays host-only (quarantined per `firmware/plan_b/README.md:10`). Do not attempt on DevKitC.
- ISR removal trades jitter-free sampling for simplicity: polling + `sleep_ms` drifts ±1-2 ms. PLL tolerates this (bandwidth 1.0 Hz); classifier-grade timing does not — which is why classification is out of scope for B7.
- Open: LRA resonance — config assumes 200 Hz (`LRA_FREQ`). If procured LRA is 150/175/235 Hz, update `fit_main.py:LRA_FREQ` and re-smoke. Mark TODO at the constant.
- Open: power brownout when LRA fires (see `docs/assembly_checklist.md` bulk-cap note). If board resets on buzz, add 10-100uF bulk cap and re-test before any gain increase.
