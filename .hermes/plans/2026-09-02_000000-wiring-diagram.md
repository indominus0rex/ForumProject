### Task 4: Verify pin assignments match config.py
**Time**: 5 min

**Cross-check script** (run to verify):
```python
import re

# Read config.py
with open("firmware/common/config.py") as f:
    config = f.read()

# Extract pins
pins = {}
for match in re.finditer(r'^(LED_PIN|LRA_PIN|LRA_PINS|I2C_SCL_PIN|I2C_SDA_PIN|TCA9548A_ADDR|GY521_ADDR)\s*=\s*(.+)', config, re.M):
    pins[match.group(1)] = match.group(2).strip()

print("Config.py pins:")
for k, v in sorted(pins.items()):
    print(f"  {k} = {v}")

# Read diagram HTML
with open("docs/wiring/wiring_diagram_4imu_no_lra.html") as f:
    diagram = f.read()

# Verify all pins present
missing = []
for k, v in pins.items():
    if v not in diagram and k != "LRA_PIN" and k != "LRA_PINS":
        missing.append(f"{k} = {v}")

if missing:
    print("\nMISSING from diagram:")
    for m in missing:
        print(f"  {m}")
else:
    print("\nAll pins verified in diagram!")
```

**Expected**: All non-LRA pins present in diagram.
