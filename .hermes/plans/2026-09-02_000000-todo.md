- [ ] 30.1 Write host script to calculate RMS amplitude:
```python
import numpy as np
import csv

def rms_amplitude(filename):
    data = []
    with open(filename) as f:
        reader = csv.reader(f)
        for row in reader:
            vals = [float(v) for v in row[1:]]
            data.append(vals)
    arr = np.array(data)
    # Calculate RMS per sample (magnitude across axes)
    rms_per_sample = np.sqrt(np.sum(arr**2, axis=1))
    return np.mean(rms_per_sample)

baseline = rms_amplitude("sessions/test_suppression_off_s01.csv")
suppressed = rms_amplitude("sessions/test_suppression_on_s01.csv")
reduction = (baseline - suppressed) / baseline * 100
print(f"Baseline RMS: {baseline:.4f}")
print(f"Suppressed RMS: {suppressed:.4f}")
print(f"Reduction: {reduction:.1f}%")
```

### Check PLL locks
```python
import math
from common.pll import PLL
from common.bandpass import BandpassFilter

fs = 100.0
pll = PLL(fs=fs, center_freq=6.0, bandwidth=1.0)
bp = BandpassFilter(fs=fs, low_hz=3.0, high_hz=12.0)

for i in range(300):
    t = i / fs
    signal = math.sin(2 * math.pi * 6.0 * t)
    filtered = bp.process_sample(signal)
    phase, freq, _ = pll.update(filtered)

print(f"Freq: {freq:.2f} Hz, Locked: {pll.locked}")
# Expected: Freq ≈ 5.8-6.2 Hz, Locked: True
```

## Risks

| Risk | Mitigation |
|------|------------|
| I2C address conflict | TCA9548A isolates all IMUs at 0x68 |
| PLL won't lock on real tremor | Increase bandwidth, check bandpass filter |
| Single LRA limitation | Use push-pull (2 LRAs) for bidirectional cancellation |
| Power brownout | Add 100µF bulk capacitor near ESP32 |
| Wire length >15cm | Keep I2C wires short, use twisted pair |
