## Future Stages

### Stage 2: Anti-Phase FES (Functional Electrical Stimulation)

**New hardware required:**
| Component | Purpose | Interface |
|-----------|---------|-----------|
| Stimulus generator board | Generate biphasic pulses | SPI or I2C |
| Surface electrodes (4-6) | Deliver stimulation to forearm muscles | Analog output |
| Isolation circuitry | Safety isolation | Hardware |
| Current limiter | Prevent over-stimulation | Hardware |

**New firmware files:**
| File | Purpose |
|------|---------|
| `firmware/common/fes.py` | FES stimulus generator control |
| `firmware/common/safety_monitor.py` | Current/voltage monitoring, emergency shutoff |
| `firmware/stages/fes_suppress.py` | FES-specific suppression stage |

**Approach:**
- Use PLL phase tracking (same as Stage 1)
- Instead of LRA, deliver biphasic current pulses to antagonistic muscles
- Pulse timing: anti-phase to tremor (same principle, different actuator)
- Amplitude: 0-20mA adjustable, current-controlled

**Safety requirements:**
- Hardware current limiter (max 20mA)
- Software watchdog (disable if no IMU data)
- Isolation barrier (patient isolation from mains)
- Impedance monitoring (detect electrode detachment)

### Stage 3: Multi-Frequency PLL (Harmonic Tracking)

**No new hardware.** Pure firmware upgrade.

**Problem**: Real tremor has harmonics (fundamental + 2nd harmonic). Single PLL only tracks one frequency.

**New firmware files:**
| File | Purpose |
|------|---------|
| `firmware/common/multi_pll.py` | Multi-frequency PLL bank |
| `firmware/common/harmonic_detector.py` | Detect tremor harmonics |

**Approach:**
- Run 2-3 PLLs in parallel (fundamental + 2nd + 3rd harmonic)
- Each PLL tracks one frequency component
- Sum anti-phase outputs for total cancellation
- Adaptive gain per harmonic

## Risks & Open Questions

1. **LRA mechanical delay varies**: Different LRAs have different response times. May need per-LRA calibration.
2. **PLL lock time**: If tremor frequency changes rapidly (e.g., during movement), PLL may lose lock. Need fast relock mechanism.
3. **Habituation**: User may adapt to constant haptic stimulation over time. Consider stochastic resonance (add noise).
4. **FES safety**: Electrical stimulation requires medical device certification. Not for home use without regulatory approval.
5. **Power consumption**: Higher sample rate + continuous PLL = more power. Battery life may be reduced.
