⚠ Critical Build Notes

  • Bypass ESP32 onboard regulator: Power the 3.3V pin directly from the AP2112K LDO. Do NOT use the VIN pin (5V input) — this would double-regulate and waste power as heat.
  • I²C pull-up resistors: Most breakout boards include 4.7kΩ pull-ups on SDA/SCL. If yours don't, add them between SDA→3.3V and SCL→3.3V.
  • Decoupling capacitors: Place C1/C2 as close as possible to the AP2112K pins (within 5mm). Use ceramic caps (X5R or X7R).
  • Wire length: Keep I²C wires under 15cm. Longer wires cause signal degradation at 400kHz.
  • Star ground: Connect all GND wires to a single point to avoid ground loops.
  • Test sequence: Power → verify 3.3V → connect ESP32 → test I²C scan → connect IMUs one by one.

🔧 Tools Required

  • Soldering iron (fine tip, 300-350°C)
  • 30AWG silicone-insulated stranded wire (red, black, green, blue, yellow)
  • Wire strippers + flush cutters
  • Multimeter (continuity + voltage)
  • Helping hands / PCB holder
  • Heat shrink tubing (2mm, 3mm)
  • Flux + solder (lead-free, 0.5mm)
