All components wired to an ESP32 development board shown beside the arm:

I²C BUS FOR ALL IMUs:
- ESP32 GPIO22 (yellow wire, labeled "SCL") → TCA9548A Multiplexer SCL pin
- ESP32 GPIO21 (green wire, labeled "SDA") → TCA9548A Multiplexer SDA pin
- ESP32 3.3V (red wire) → TCA9548A VCC
- ESP32 GND (black wire) → TCA9548A GND
- TCA9548A Address Pins (A0,A1,A2) all connected to GND (sets multiplexer address to 0x70)
- TCA9548A Channel 0 (CH0) → IMU1 SCL/SDA + 3.3V/GND (labeled "CH0 → IMU1")
- TCA9548A Channel 1 (CH1) → IMU2 SCL/SDA + 3.3V/GND (labeled "CH1 → IMU2")
- TCA9548A Channel 2 (CH2) → IMU3 SCL/SDA + 3.3V/GND (labeled "CH2 → IMU3")
- TCA9548A Channel 3 (CH3) → IMU4 SCL/SDA + 3.3V/GND (labeled "CH3 → IMU4")
- All IMU AD0 pins tied to GND (so each sees address 0x68 on its channel)

- ESP32 GPIO20 (light-blue wire, labeled "PWM3") → LRA3 + terminal, LRA3 - terminal → GND
